Project Overview

仓库里已经有 baseline、攻击、防御、实验日志和数据集快照，适合直接做组内展示。

Method Stack

从 clean baseline 到白盒攻击，再到防御评估，链路是完整的。

Baseline

支持 notebook-style 三分类和 logprob 二分类两条口径，便于和旧实验对齐。

GCG

使用 nanogcg 做 token-level white-box suffix 优化，Qwen3 路径里关闭了 prefix cache。

Defense

仓库里有 PerplexityFilter、SmoothLLM、SelfReminder 和 ParaphraseDefense。

Metric Glossary

QWKQuadratic Weighted Kappa，衡量评分一致性。
Accuracy有效样本上的分类正确率。
ASRincorrect 样本被攻成 correct 的比例。
Confusion Matrix看攻击把错误质量推向了哪一类。
