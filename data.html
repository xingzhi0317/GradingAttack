Main branch data notes

这里说明 main 分支数据来源

展示页现在只使用 `main` 分支公开文件。main 中没有提交实验 logs/result， 所以不再展示之前的总体准确率或 ASR 数字。

README

main README 将项目描述为 LLM-based ASAG 的 unified adversarial evaluation framework。

Datasets

main 公开了 `gaokao-2023`、`gsm8k`、`math`、`math23k` 和 `scientsbank`。

SciEntsBank

`dataset/scientsbank.jsonl` 在 main 中共有 5000 行，首页 demo 样本来自其中一条 incorrect 记录。

GCG config

目标是 `<answer>correct</answer>`，`num_steps: 100`，`search_width: 64`，`topk: 64`。

RolePlay config

main 中直接保存了一段 role-playing adversarial prompt，用于 prompt-level attack。

Result scope

main 没有包含 logs/result 文件，页面不会声称 main 分支中不存在的评估结果。
